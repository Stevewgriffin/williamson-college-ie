Populi Data Import

Williamson College uses Populi as its LMS/SIS. Export CSV/XLS files from Populi by module and import them here. Data populates institutional metrics, SLO assessments, and the GASW. Only courses and faculty that actually ran in a module are assessed.

① Student Roster (Recommended First) ▼

Upload the Students export from Populi (People > Students > Export). This maps each Student ID to their actual degree program (BSBA, BSML, ADL, etc.) so enrollment data is categorized correctly. Contains: Student ID, First Name, Last Name, Standing, Program, Degree, GPA, Credits.

or drag and drop CSV/XLS/XLSX file here

② Enrollment Report (from Populi Academics > Reporting > Enrollment) ▼

Upload the Enrollment export from Populi (Academics > Reporting > Enrollments > Export). Contains Student ID, Name, Program, Academic Term, Course, Status, Delivery Method, Grade (numeric), Letter grade, Term GPA, Department, and Faculty. Courses are automatically mapped to your 8 programs. Columns typically include: Student, Student ID, Program, Course, Section, Faculty, Status, Final Grade, Term, Credits.

or drag and drop CSV/XLS/XLSX file here

Gradebook / SLO Rubric Data ▼

Upload gradebook export with rubric scores from Populi. SLO rubric criteria will be mapped to program SLOs automatically. Columns typically include: Student, Course, Assignment, Rubric Criterion, Score, Max Score.

or drag and drop CSV/XLS/XLSX file here

Attendance & Completion Report ▼

Upload attendance report from Populi (Academics > Reporting). Contains Student, Course, Academic Term, Present, Excused, Tardy, Absent, and % Attended columns. Data is aggregated by course automatically.

or drag and drop CSV/XLS/XLSX file here
